# ELP Web + Mobile-ready API

This project now includes:

- React frontend (mobile-first UI)
- Express backend API (`server/index.ts`)
- Shared data contract for web and future mobile app

## Run Locally

1. Install dependencies:
   `npm install`
2. Run web + backend together:
   `npm run dev:all`
3. Open web:
   [http://localhost:3000](http://localhost:3000)
4. API base:
   [http://localhost:4000/api](http://localhost:4000/api)

## Mobile API Contract

See `MOBILE_API.md` for full endpoint list and payload examples.
